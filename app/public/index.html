How a change reaches this page

  1. PushA commit lands on GitHub and Jenkins picks it up.
  2. CheckoutJenkins fetches that exact commit.
  3. TestUnit tests run inside a Docker build stage.
  4. BuildThe production image is tagged with the build number.
  5. Smoke testA throwaway container must answer its health check.
  6. DeployThe old container is swapped for the new one.
  7. VerifyJenkins confirms the live build number. If not, it rolls back.
